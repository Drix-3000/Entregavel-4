# Entregavel-4
Adiciona arquivos ```.test.js``` para funcoes de javascript usando a biblioteca JEST

## Requisitos 
Node js
Terminal ou VS CODE

## Como instalar
1 - baixe os arquivos na sua maquina usando Git ou pelo navegador
2 - Abra pelo TERMINAL ou VS CODE
3 - execute o comando ``npm install --save-dev jest``
4 - execute ``npm test`` veja o resultado no terminal
