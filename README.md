# Entregavel-4
Adiciona arquivos ```.test.js``` para funcoes de javascript usando a biblioteca JEST

## Requisitos 
> - Node js
> - Terminal ou VS CODE

## Como instalar
- baixe os arquivos na sua maquina usando Git ou pelo navegador
- Abra pelo TERMINAL ou VS CODE
- Execute o comando ``npm install --save-dev jest``
- Execute ``npm test`` veja o resultado no terminal
